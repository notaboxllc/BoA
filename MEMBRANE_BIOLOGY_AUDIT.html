0. The most important structural finding

There are two membrane models in the tree, and the audit request is written in the vocabulary of the legacy one. Every parameter named in the request exists — but the formin/Arp/capping/align/yield family belongs to the legacy node-lattice membrane, which every DTS config explicitly disables (buildMembraneSheet:false; forminConc:true:0.0; arpConc:true:0.0). The live production model is the DTS (dynamically-triangulated surface) family of dts* parameters. The legacy names are present, mostly runtime-mutable and documented, but dead on the production path.

1. Matches biology MATCHES

  • Arp2/3 never de-novo nucleates. Membrane.branchStep only creates a daughter off an existing FilSegment mother whose barbed tip is within ~60 nm of the cortex and sits in a high local-Arp region. No path lets the Arp field alone spawn a filament. (core requirement #2)
  • Formin is the sole mother source. forminStep → makeForminMother builds an uncapped linear seed (no Arp junction) that becomes a branching template. Mother-generation (formin) and daughter-generation (Arp2/3) are cleanly separated.
  • Branch angle = 70° (arp23AlphaAngle), the canonical dendritic Arp2/3 angle, with helical-azimuth modulation so daughters fan around the mother.
  • Barbed end held at the cortex. With dtsForminGrowOut=true the mother is seeded barbed-end-out (uVec = outward), end2 linked to the vertex; the pointed end trails into cytoplasm — the correct formin geometry.
  • Mogilner–Oster ratchet. ratchetPolyFactor throttles barbed-end elongation by exp(−F·(δ−gap)/kT) using the tip→membrane clearance (end2TipC) written by the DTS collision. Growth stalls as load → stall force and resumes as the cortex yields — polymerization genuinely becomes protrusion.
  • Continuous surface, not a porous lattice. segmentVsMembrane samples the whole rod against tiled triangles (no face-center gaps) and distributes the push barycentrically to 3 vertices. The Stage-3-prep containment sweep passed in all orientations.
  • Finite mother seeding. dtsForminPool=1, dtsForminConsume=1, dtsForminRecover=0 ⇒ ~1 mother per hot vertex, no recovery — a hard, finite cap. (#3, #4)
  • Arp reaction–diffusion. Hot patches are clamped sources; bulk decay (dtsArpDecay) + per-branch consumption (dtsArpConsumePerBranch) are the sinks; halo length ≈ √(D/k). Source-at-NPF / sink-in-bulk is correct. (#10)

2. Coarse but acceptable COARSE-OK

  • Force-sensitive formin release (forminCanHold): exponential catch under compression, reference force hard-coded at 2 pN. Plausible but uncalibrated; configs set forminRelease:0 anyway.
  • Daughter network embedding is approximated by a rotational-drag floor (filDragMinMonomers), critically-damped junctions (arpTransFracMove=1.0), and inherited Brownian damping (heldBrownFactor) rather than explicit geometry. Phenomenological but stable.
  • Held-mother thermal damping (forminBarbedBrownianFactor=0.05, arpHeldBrownianFactor=0.02): a held filament should have suppressed thermal; the 20×/50× factors are unprincipled but qualitatively right.
  • DTS "yield" is native, not the legacy membraneYield flag. Actin push moves vertices through the ordinary overdamped integrator; bending+area+volume energies resist; subcycleRelaxAll is retired. This is more physical than the legacy re-apply-each-Jacobi-pass scheme. (#12)
  • dtsMaxFilaments hard cap as a runaway backstop — blunt but harmless if consumption feedback is the real limiter.
  • Solid shell, not yet a fluid bilayer — bond flips (design §4) are unimplemented, so there is no lateral lipid flow / area transport into a finger yet. Acceptable for protrusion tests; state it explicitly.

4. Answers to the 13 audit questions

  1. Separates formin mothers from Arp daughters? Yes — distinct paths/flags (forminMother vs Arp23 junction). ✔
  2. Arp de-novo nucleation contradicting biology? Not on the dendritic path. ActA/ProteinNode de-novo exist but are off in lamellipodium configs. ✔/flag (P4)
  3. Does the formin pool cap mothers per node? Yes — dtsForminPool/Consume give ~1 mother/hot-vertex. ✔
  4. forminRecover = optional re-recruitment, not unlimited? Yes, default 0 = finite. ✔
  5. motherTetherDepth biologically useful placement? Works on the legacy path; the DTS analog dtsForminStandoff (0.05 µm off-surface) is the validated one. ✔ (DTS); legacy param unused.
  6. membraneAlignAngle = barbed dir vs outward normal, correct? Legacy mechanism is correct (90°=tangent, <90°=dendritic tilt) but doesn't run on DTS. (P2)
  7. membraneAlignTorque too rigid for floppy formin? Opposite — on DTS it's absent; the DTS torque spring targets the wrong frame at ~zero strength. (P2)
  8. membraneCapDist localizes growth without killing the network? Mechanism sound but disabled (=0) on the live path. (P1)
  9. branchMembraneDist realistic / not too volumetric? Legacy param unused; DTS uses a fixed ~60 nm barbed-tip-near-cortex gate — appropriately thin, near the membrane. ✔
  10. arpLocalField plausible NPF field? Legacy version superseded; DTS dtsArp* field is a correct source/diffuse/sink. ✔
  11. membraneFaceCollideOn makes a real surface? That flag doesn't exist on DTS; dtsActinCollide drives a genuine continuous-surface collision. ✔ (caveat P3 for legacy drag).
  12. membraneYield converts push→protrusion without instability? DTS yields natively (no flag); the stability risk is the 1/sinθ bending blow-up (P5), not the caps.
  13. Old params misleading/unused? Yes — the entire legacy node-lattice param family is live-in-code, dead-on-path. Deprecate/document. (see §6)

5. Recommended parameter-only changes PARAMS

  1. Enable cortex-localized capping on dendritic DTS configs (P1). Set membraneCapDist ≈ 0.1–0.15 µm in dtsMembraneDendritic / dtsMembraneForminBranch so barbed ends cap once they fall >~1 monomer behind the cortex. end2TipC already feeds it. Highest-value biology fix; config-only.
  2. Keep dtsForminRecover:0, dtsForminPool:1, forminRelease:0 for bonded studies — already correct in the bond/branch configs; don't raise without intent.
  3. Leave membraneAlignTorque low/off as a deliberate floppy-formin choice — but see code change C3 (it does nothing on DTS regardless).
  4. dtsBranchRate: keep moderate (20–40). Branch count ≈ dtsBranchRate·arp is exponentially sensitive — tune density here, length via biochemDeltaT/actinConc.

7. Recommended validation run

Build on dtsMembraneForminBranch (already: one hot patch, dtsForminPool:1, dtsArpOn, dtsActinCollide, forminRelease:0):

  • Run A — capping/orientation baseline: as-is, add membraneCapDist:0.12, stiff membrane (dtsKappaArea:0.15, dtsTargetReducedVol:1.0 — "yield off"). Outputs: mother count, branch count, capping fraction, barbed-tip→membrane distance, protrusion displacement (expect ~0).
  • Run B — yield on: same, soften the volume constraint (dtsKappaVolume:1e-14) so the cortex can bulge. Outputs: same metrics + radial displacement (expect a bounded protrusion at the patch).

Compare A vs B for: finite mothers (≈1/hot-vertex), branches localized to the patch, capping fraction rising away from the cortex, and push→protrusion only in B. Watch [DTS-E] |F|max for the P5 1/sinθ blow-up.

Bottom line. The live DTS lamellipodium module is in good biological shape on the hard requirements — formin-only mothers, Arp2/3-only branching off them, a real reaction-diffusion NPF field, a genuine continuous-surface collision, and a real Mogilner–Oster ratchet. The gaps are (1) cortex-localized capping is implemented but switched off, (2) mother orientation bias toward the normal isn't wired on DTS (the good mechanism is legacy-only; the DTS one points at the wrong frame), and (3) a large, mostly-dead legacy parameter surface that makes the model hard to read. None require a refactor — one config flag, one frame fix, and documentation close most of it.
