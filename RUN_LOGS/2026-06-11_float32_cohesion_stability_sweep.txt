Part 1 — Float32 verdict for the minifilament cohesion BODY reaction
====================================================================
Date 2026-06-11. Branch float32-stability-diag. Config boa10-singleMiniFil
(single bipolar minifilament, N dimers/end, NO actin), 300 steps, 60 frames.
Metric: analyze_minifil.py (span / body-axis cumulative wander / COM jitter)
+ "crazy"/NaN guard count. Divergence = crazy>0 OR wander>300 deg.

Schemes (all SET on the body slot -> NO RMW confound):
  lag  = -gpu default        : float32, 1-step device-resident lag (PRODUCTION)
  sync = -gpu BOA_COH_SYNC=1 : float32, SYNCHRONOUS SET (no lag)
  cpu  = no -gpu             : float64, synchronous SET (full-CPU oracle)
PRODUCTION OPERATING POINT: fm(myoMiniFilFracMove)=0.07, N(numMyoDimersEachEnd)=8 -> fm*N=0.56.

VERDICT: MISATTRIBUTION of the production-fix rationale + a narrow genuine f32 effect.
 1. At production (fm=0.07): sync float32 STABLE (22.7) ~= oracle (20.4). The journal's
    "190deg synchronous divergence" was the cross-step RMW confound, not float32. Lag NOT
    load-bearing at production.
 2. Threshold tracks the fm*N stiff-coupling product (stiff explicit-integration instability):
      float32-sync diverges ~product 1.5 (N8 fm~0.19 ; N16 fm~0.09)
      float64-sync diverges ~product 1.9 (N8 fm~0.23 ; N16 fm~0.12)
      float32-LAG  stable to fm=4.0 (product 32) -- never broke
    => the lag extends the margin >20x: a SCHEME effect (would help float64 too), not precision.
 3. Genuine but NARROW float32 margin-narrowing (~20%, product 1.5 vs 1.9) at fm=0.20 N=8
    (float32-sync DIVERGED, float64-sync STABLE), seed-marginal (s2 held), 2.5-4x above the
    production point. CAVEAT: device also differs in Brownian RNG/integration, so ~20% is an
    UPPER BOUND on pure precision.
 V2: keep a deliberate lag (or semi-implicit / softer fracMove) for the stiff cohesion term as a
 STIFF-STABILITY measure; f64 on that term is unnecessary and would not remove the lag's need at
 high stiffness. >2.5x margin at production even for plain synchronous float32.
