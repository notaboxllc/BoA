Minifil-ON turnover on device — packRange cast desync: reproduction, fix, validation
=====================================================================================
Date: 2026-06-11   Machine: aorus1 (Java 21 + TornadoVM 4.0.1-dev PTX)
Config: ParameterFiles/boa10-64Seg-dyn (100 fil + 100 minifil + cofilin sever +
        kRdmNuc nucleate + poly/depoly; noMonomersSimd:false; deltaT 1e-4; 5000 steps)

WHAT THE CRASH IS
-----------------
GPUMoveThing.packRange / packDynamicRange iterate move-slots, read the cached
brownianRule[slot] and the live occupant theThings[gpuThingIndices[slot]], and
dispatch the Brownian scale by rule. The RULE_FIL branch casts (FilSegment) t.
The historical crash: a slot cached RULE_FIL whose live occupant is a
MyoMiniFilament -> ClassCastException. Root cause is a rules[]/theThings[] DESYNC:
the cached slot maps (built by classifyThings()) describe an older theThings[]
layout than the one the pack reads.

The only mutation that moves a different-typed Thing into an existing slot's index
without an append is removeThing()'s swap-compaction (last Thing swapped into the
freed slot). The 2026-06-09 fix (Thing.removeThing, commit 197bed4) signals
GPUMoveThing.markTopologyDirty() on every swap (swapId != lastId), forcing a
classifyThings() refresh at the next onStepStart BEFORE the next pack. Phase A
(1d7dcc3) added the RULE_MINIFIL pack branches. On HEAD both are present.

REPRODUCTION (the discipline: prove the mechanism on demand)
-----------------------------------------------------------
1. Production build (topologyDirty-on-swap ON), boa10-64Seg-dyn, seeds 1 & 2,
   5000 steps each: BOTH rc=0, NO ClassCastException, no NaN. The crash does not
   reproduce on HEAD — the 2026-06-09 fix keeps the slot maps consistent before
   every pack, so no minifil ever sits in a RULE_FIL slot at pack time.

2. Fault injection: BOA_DISABLE_TOPODIRTY_ON_SWAP=1 (Thing.java diagnostic flag,
   default OFF) skips the markTopologyDirty() signal on swap — deliberately
   reintroducing the historical staleness. Run boa10-64Seg-dyn seed 1, guard ON:
       [PACK_DESYNC] step=395 slot=9606 cachedRule=3 liveType=FilSegment liveRule=0
       [STATS] gpuMoveThing ... planRebuild=1 packRuleDesync=538
       rc=0  (completed, NO crash)
   => The desync IS real and frequent (538 slot/rule mismatches over 5000 steps)
      when the 2026-06-09 signal is removed. It is bidirectional; the historical
      ClassCastException is the (cachedRule=RULE_FIL, live=MyoMiniFilament) subset.
      The guard caught every one and self-healed -> no crash.

THE FIX (type-consistent pack dispatch)
---------------------------------------
GPUMoveThing.reconcilePackRule(slot, t, cachedRule): dispatch on the LIVE occupant
type (ruleForGpuThing) rather than the cached rule. When live != cached:
  - count it (packRuleDesyncCount, surfaced as [STATS] packRuleDesync=N),
  - log the first occurrence,
  - markTopologyDirty() so classifyThings() rebuilds slot maps + joint lists next
    step.
packRange and packDynamicRange both route their per-slot rule through it. Because
the FilSegment cast now only runs when the LIVE type is FilSegment, a stale cached
rule can NEVER throw a ClassCastException — the crash class is closed structurally,
independent of the topologyDirty signal. In production (signal ON) the guard never
fires (packRuleDesync=0); under fault injection it absorbs all 538 events.

Force-coverage exactly-once: unchanged. reconcilePackRule only selects the Brownian
scale + makes the cast safe; it touches no force-sum / joint-apply code. Each slot's
force/pose still packs from soaForce[thingIdx]/soaCoord[thingIdx] via the same
gpuThingIndices[slot] (which co-varies with brownianRule[slot]; both are written as
a pair in classifyThings, so gpuThingIndices points at the live occupant whose force
we pack — only the rule label could lag, and that is what we reconcile).

Minifil Brownian: a RULE_MINIFIL slot already gets sMiniFilBrownian (=
Env.myoMiniFilBrownianScale) in both pack functions (added Phase A 1d7dcc3); the
reconciliation makes that dispatch robust to a stale cached rule too.

NOTE — do not SIGTERM a TornadoVM run mid-kernel: it leaves the CUDA context dirty
and the next run floods cuLaunchKernel->701. Let runs complete or time out cleanly.

DIAGNOSTIC HOOKS (default OFF, kept as residency tooling)

  BOA_PACK_RAW_CAST=1              (GPUMoveThing) — bypass reconcile (raw cached-rule
                                    dispatch + cast) to exhibit pre-guard behavior.
