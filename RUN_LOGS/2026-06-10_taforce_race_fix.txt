Cross-pool taForce race fix — audit + validation
aorus1, branch cpu-taforce-race-fix (off main). 2026-06-10.
================================================================================

ROOT CAUSE (confirmed earlier; see JOURNAL race-confirmation entry)
  incForceSum accumulates into a per-thread row taForce[tid] (+ dirtyCounts[tid],
  dirtyIndices[tid]); tid is each worker's LOCAL index within its own ThreadSet,
  and taForce has only allThreadCt(=16) rows — the design assumes ONE pool writes
  forces at a time. Waves that release 2+ force-writing pools concurrently make
  worker-0 of each pool race on taForce[0] → dropped += updates / corrupted dirty
  bookkeeping → restoring forces silently lost → progressive non-diffusive
  dissolution. SoA-inc migration regression (pre-migration incForceSum wrote the
  shared sum under synchronization).

  Ladder: single myosin (1 pool) holds; dimer (Myosin+MyosinDimer) one myosin
  dissolves; minifilament (+MyoMiniFilament) falls apart; gliding (1 pool) works.
  Methodological note: single-pool tests are BLIND to this class of bug — the
  earlier "forces applied, no regression" verdict came from a single-myosin test.

CORRECTIONS to the prompt's tentative list:
  - membrane is NOT a race: NodeLink (wave 14) and StickyNode (wave 15) are on
    DIFFERENT waves, one pool each. Not serialized.
  - myoJoints2 is a 4-pool collision (ProteinNode + MyoMiniFilament + ChamberMyo
    + ChamberMyoD via Crucible.keepMyosin*OnSurface), not the 3 assumed.
  - ActA is on its OWN wave constant that ALIASES onto xLinkStart (both = 6), so
    the xLink dispatch does release all 3.

Single-pool waves are race-free (a pool's own 16 workers have distinct tids
0..15). The collision/mesh force writes (FilSegment.incForceSum from ckMesh/ckMots)
are single-pool per wave → unaffected.

FINAL SERIALIZED SET: waves 6 (xLink), 7 (myoJoints1), 8 (myoJoints2). Three
dispatch sites, routed through runForceWave().

--------------------------------------------------------------------------------
THE FIX (BoxOfActin.java only)
--------------------------------------------------------------------------------
- runForceWave(start,stop): default serializes the wave's pools via
  startAndWaitEachThreadSet (divideAndConquer+regroup per pool, in order) so two
  pools never write taForce concurrently. Within-pool parallelism preserved (each
  pool still fans out its 16 workers). BOA_CONCURRENT_FORCES=1 restores the legacy
  concurrent dispatch (A/B + rollback). Default = serialized.
- xLink, myoJoints1, myoJoints2 dispatch pairs replaced with runForceWave().
- (validation fixture) BOA_SINGLE_DIMER=1 builds a single free MyosinDimer.
No physics/param/strength/GPU changes.
